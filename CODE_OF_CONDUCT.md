# Code of conduct

This applies to the issues, pull requests and discussions of the security
testing platform in [`faisal-security-lab/`](faisal-security-lab/README.md).

## What is expected

- Be respectful. Disagree about the work, not about the person.
- Assume good intent, and say plainly what you mean.
- Keep discussions on the subject of the issue or pull request.
- Accept that the maintainer decides what is merged.

## What is not accepted

- Insults, harassment or discrimination of any kind.
- Publishing someone else's private information.
- Asking for, or offering, help with testing systems without the permission of
  their owner. This project is for defensive work on systems you own or are
  authorized to test.
- Posting real credentials, or details of a vulnerability that has not been
  fixed, in public.

## If something goes wrong

Use GitHub's "Report content" on the comment or the profile concerned; that
report goes to GitHub. To reach the maintainer privately, use the route in
[SECURITY.md](SECURITY.md) and say that it is a conduct report. The maintainer
may edit or remove comments, close or lock a discussion, and block an account
that keeps breaking these rules.
