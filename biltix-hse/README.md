# بلتكس HSE — مركز قيادة السلامة والصحة المهنية
## Biltix HSE — Occupational Health & Safety Risk Command Center

نظام إدارة مخاطر السلامة والصحة المهنية لمنصة **بلتكس (Biltix)** — لوحة قيادة هندسية عصرية، عربية (RTL)، تعمل بدون أي خطوة بناء، وتُنشر كموقع ثابت على Vercel.

### ما الذي يقدمه النظام؟

| القسم | الوصف |
|---|---|
| **SEC-01 نظرة عامة** | مؤشر السلامة الكلي (Safety Index)، مؤشرات LTIFR / TRIR، مصفوفة المخاطر 5×5، اتجاه الحوادث، حالة التصاريح، أداء المواقع، الإجراءات العاجلة |
| **SEC-02 الرادار الحي** | أربعة رادارات متحركة باستمرار على Canvas: رادار المخاطر (مسح دائري)، رادار الحساسات (قطبي حي)، رادار مخطط الموقع (حركة العمال والمعدات)، رادار الامتثال ISO 45001 |
| **SEC-03 سجل المخاطر** | سجل كامل مع تسلسل الضوابط الهرمي، المخاطر الكامنة مقابل المتبقية، الإضافة والتعديل والحذف مع الحفظ المحلي |
| **SEC-04 الحوادث** | الحوادث والحوادث الوشيكة، تحليل باريتو للأسباب الجذرية، مسار التحقيق بخمس خطوات، الإجراءات التصحيحية |
| **SEC-05 تصاريح العمل** | لوحة كانبان لتصاريح العمل (أعمال ساخنة، أماكن مغلقة، ارتفاعات، عزل كهربائي…) مع عدّادات انتهاء حية |
| **SEC-06 التفتيش والتدقيق** | جدولة الجولات، نسب الإنجاز، الملاحظات المفتوحة والمغلقة |
| **SEC-07 التدريب والكفاءات** | مصفوفة التدريب (العمال × الدورات)، الشهادات المنتهية والقريبة من الانتهاء |
| **SEC-08 الامتثال ISO 45001** | درجات البنود 4–10، الفجوات، السجل القانوني السعودي (نظام العمل، لائحة السلامة والصحة المهنية، كود البناء السعودي، الدفاع المدني، التأمينات الاجتماعية) |
| **SEC-09 التكاملات** | 16 موصلاً (منصة بلتكس، Biltix DMS، بوابة الحساسات، الكاميرات الذكية، الأجهزة القابلة للارتداء، بوابات الدخول، الأرصاد، GOSI، الموارد البشرية، ERP، Slack، Teams، WhatsApp، البريد، SMS، Webhooks، Google Sheets، Supabase، Power BI) مع مصدر بيانات قابل للتهيئة |
| **SEC-10 التقارير** | تقرير شهري قابل للطباعة/PDF، تصدير CSV/JSON، مشاركة، تقرير صوتي عربي |
| **SEC-11 الإعدادات** | السمة الداكنة/الفاتحة، الأرقام العربية/اللاتينية، ألوان الهوية وشعار الشركة، إدارة البيانات |

### الاتصال بالأنظمة الحقيقية

- **مصدر البيانات**: من قسم التكاملات اختر `JSON API` أو `Google Sheets CSV` أو `Supabase` وأدخل الرابط والمفتاح، ثم «اختبار الاتصال» و«استيراد المخاطر». القالب القياسي للأعمدة قابل للتنزيل من نفس الشاشة.
- **تنبيهات Webhook**: أدخل رابط Webhook (Slack / Teams / n8n / Zapier) ليستقبل التنبيهات الحرجة.
- **الوضع الافتراضي**: محاكاة حية ببيانات توضيحية واقعية تُعاد مزامنة تواريخها تلقائياً مع تاريخ اليوم.

### التشغيل محلياً

```bash
cd biltix-hse
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

### النشر

المجلد `biltix-hse/` هو جذر النشر (موقع ثابت بالكامل). على Vercel: اربط المستودع واضبط **Root Directory** إلى `biltix-hse` بدون أمر بناء.

### المعمارية

راجع `docs/ARCHITECTURE.md` — العقد البرمجي الكامل للوحدات (tokens، مخطط البيانات، واجهات الرسوم والرادارات، محرك البث الحي).

> ملاحظة: تعذّر الوصول إلى `biltix.sa` من بيئة التطوير السحابية أثناء البناء، لذلك صُممت الهوية البصرية على أساس المعلومات المتاحة عن بلتكس (منصة سعودية لإدارة مشاريع البناء)، وجُعلت ألوان الهوية والشعار قابلة للتعديل مباشرة من شاشة الإعدادات.
