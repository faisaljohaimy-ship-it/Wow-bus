# بلتكس — منصة إدارة المخاطر بالذكاء الاصطناعي
## Biltix AI Risk Management Platform — Risk Cockpit

منصة إدارة مخاطر بالذكاء الاصطناعي لمنصة **بلتكس (Biltix)** مبنية وفق المقترح التفصيلي للعميل (المعمارية v2): خمسة مجالات مخاطر (العقود، المواد والتوريد BoM، الجدول الزمني، الموقع والسلامة، التكلفة)، طبقة تحقق وتنظيف للبيانات، تصنيف فوري **أحمر/أصفر/أخضر** ونوع المخاطرة **مالي/سلامة/تأخير/نزاع**، تنبيهات وتصعيد ومهام معالجة مُتتبعة مع كتابة عكسية إلى تطبيق بلتكس، وموصلات مؤسسية (Primavera P6، Autodesk APS، Oracle ERP/CRM). لوحة قيادة هندسية عصرية، عربية (RTL)، تعمل بدون أي خطوة بناء، وتُنشر كموقع ثابت على Vercel.

> **الرابط الحي | Live:** https://biltix-risk-ai.vercel.app

| القسم | الوصف |
|---|---|
| **CPT-00 قمرة القيادة** | ترتيب قراءة واحد: العنوان ونطاق البيانات، أربعة مؤشرات تنفيذية بحلقات دائرية، خمس بطاقات مجالات مع الدرجة الموحدة ورابط الأوزان، التحليل (توزيع الشدة، مصفوفة الاحتمال × الأثر، الاتجاه، المتأصلة مقابل المتبقية)، الإجراءات ذات الأولوية، والسجل التفصيلي؛ فيديو «كيف تعمل المنصة» بالعربية والإنجليزية عند الطلب فقط |
| **AIR-01 سجل المخاطر الذكي** | كل مخاطرة بدرجة وتفسير بلغة واضحة ودليل من نظام المصدر وتوصية معالجة؛ تدفق المستخدم الكامل: قبول التوصية بنقرة، تعديل/تجاوز مع تسجيل السبب، إسناد مالك وموعد، تصعيد فوري، معاملات استجابة لكل صاحب مصلحة |
| **AIR-02 مهام المعالجة** | لوحة كانبان للمهام الناتجة عن التوصيات مع حالة الكتابة العكسية إلى Biltix PM (محاكاة، غير متصلة) وإعادة تعليم المتأخر |
| **AIR-03 التنبيهات والتصعيد** | قائمتا التصعيد الفوري والتنبيهات القياسية، عتبات التنبيه، قنوات البريد/Slack/Teams/WhatsApp (غير متصلة: يُسجَّل التوجيه فقط) |
| **DOM-01 مخاطر العقود** | تصنيف البنود (غامضة، شروط دفع وغرامات، تأمين/تعويض مفقود، التزامات) مع صياغات بديلة ومعايير مرجعية، تقويم الالتزامات، تركّز المقاولين من الباطن |
| **DOM-02 مخاطر المواد والتوريد** | تقلب أسعار السلع مع توقعات، تركّز الموردين والمورد الوحيد، تباين الكميات BoQ↔BIM، أزمنة التوريد الطويلة، تطابق المواصفات |
| **DOM-03 مخاطر الجدول الزمني** | انزلاق المسار الحرج باحتمالات تأخير، محاكاة مونت كارلو (P50/P80/P90)، الموارد، الطقس، الموافقات التنظيمية، أداء المقاولين من الباطن |
| **DOM-04 مخاطر التكلفة** | مؤشرات القيمة المكتسبة CPI/SPI/EAC/ETC/VAC، توقع التكلفة، تعرض العملات، زحف أوامر التغيير، مؤشر العمالة |
| **PLT-01 محرك الذكاء الاصطناعي** | خمسة خطوط نماذج (عقود NLP، توقع BoM، نموذج الجدول، صور وتقارير الموقع، توقع التكلفة) مع طبقة تقييم وتفسير مشتركة، الدقة والانحراف (تظهر «غير مُقاسة»)، القبول مقابل التجاوز (الإنسان في الحلقة)، سجل التدقيق |
| **PLT-02 جودة البيانات** | طبقة التحقق والتنظيف: فحص المخطط، إزالة التكرار، الاكتمال، الاتساق، قائمة الحجر |
| **PLT-03 خارطة الطريق والمقترح** | المعمارية ذات الطبقات الخمس وإضافات v2، نطاق العمل، الافتراضات، المعالم M0–M4 مع نسب دفع قابلة للتعبئة |

### الاتصال بالأنظمة الحقيقية

- **مصدر البيانات**: من قسم التكاملات اختر `JSON API` أو `Google Sheets CSV` أو `Supabase` وأدخل الرابط والمفتاح، ثم «اختبار الاتصال» و«استيراد المخاطر». القالب القياسي للأعمدة قابل للتنزيل من نفس الشاشة.
- **تنبيهات Webhook**: أدخل رابط Webhook (Slack / Teams / n8n / Zapier) واختبره بطلب POST حقيقي من المتصفح؛ تمرير التنبيهات تلقائياً يحتاج خادماً غير موجود في هذا الإصدار.
- **الوضع الافتراضي**: محاكاة حية ببيانات توضيحية واقعية تُعاد مزامنة تواريخها تلقائياً مع تاريخ اليوم.
