# بلتكس — منصة إدارة المخاطر بالذكاء الاصطناعي
## Biltix AI Risk Management Platform — Risk Cockpit

منصة إدارة مخاطر بالذكاء الاصطناعي لمنصة **بلتكس (Biltix)** مبنية وفق المقترح التفصيلي للعميل (المعمارية v2): خمسة مجالات مخاطر (العقود، المواد والتوريد BoM، الجدول الزمني، الموقع والسلامة، التكلفة)، طبقة تحقق وتنظيف للبيانات، تصنيف فوري **أحمر/أصفر/أخضر** ونوع المخاطرة **مالي/سلامة/تأخير/نزاع**، تنبيهات وتصعيد ومهام معالجة مُتتبعة مع كتابة عكسية إلى تطبيق بلتكس، وموصلات مؤسسية (Primavera P6، Autodesk APS، Oracle ERP/CRM). لوحة قيادة هندسية عصرية، عربية (RTL)، تعمل بدون أي خطوة بناء، وتُنشر كموقع ثابت على Vercel.

> **الرابط الحي | Live:** https://biltix-risk-ai.vercel.app

### قمرة قيادة المخاطر (Part B)

| القسم | الوصف |
|---|---|
| **CPT-00 قمرة القيادة** | الدرجة الموحدة للمخاطر (0–100) بأوزان المجالات الخمسة، شريط تدفق البيانات الحي (التقاط → تحقق → بحيرة البيانات → تقييم → تصنيف → تنبيه → مهمة → إغلاق)، أعلى المخاطر الحمراء، صحة خطوط الذكاء الاصطناعي |
| **AIR-01 سجل المخاطر الذكي** | كل مخاطرة بدرجة وتفسير بلغة واضحة ودليل من نظام المصدر وتوصية معالجة؛ تدفق المستخدم الكامل: قبول التوصية بنقرة، تعديل/تجاوز مع تسجيل السبب، إسناد مالك وموعد، تصعيد فوري، معاملات استجابة لكل صاحب مصلحة |
| **AIR-02 مهام المعالجة** | لوحة كانبان للمهام الناتجة عن التوصيات مع حالة الكتابة العكسية إلى Biltix PM وإعادة تعليم المتأخر |
| **AIR-03 التنبيهات والتصعيد** | قائمتا التصعيد الفوري والتنبيهات القياسية، عتبات التنبيه، قنوات البريد/Slack/Teams/WhatsApp |
| **DOM-01 مخاطر العقود** | تصنيف البنود (غامضة، شروط دفع وغرامات، تأمين/تعويض مفقود، التزامات) مع صياغات بديلة ومعايير مرجعية، تقويم الالتزامات، تركّز المقاولين من الباطن |
| **DOM-02 مخاطر المواد والتوريد** | تقلب أسعار السلع مع توقعات، تركّز الموردين والمورد الوحيد، تباين الكميات BoQ↔BIM، أزمنة التوريد الطويلة، تطابق المواصفات |
| **DOM-03 مخاطر الجدول الزمني** | انزلاق المسار الحرج باحتمالات تأخير، محاكاة مونت كارلو (P50/P80/P90)، الموارد، الطقس، الموافقات التنظيمية، أداء المقاولين من الباطن |
| **DOM-04 مخاطر التكلفة** | مؤشرات القيمة المكتسبة CPI/SPI/EAC/ETC/VAC، توقع التكلفة، تعرض العملات، زحف أوامر التغيير، مؤشر العمالة |
| **PLT-01 محرك الذكاء الاصطناعي** | خمسة خطوط نماذج (عقود NLP، توقع BoM، نموذج الجدول، صور وتقارير الموقع، توقع التكلفة) مع طبقة تقييم وتفسير مشتركة، الدقة والانحراف، القبول مقابل التجاوز (الإنسان في الحلقة)، سجل التدقيق |
| **PLT-02 جودة البيانات** | طبقة التحقق والتنظيف: فحص المخطط، إزالة التكرار، الاكتمال، الاتساق، قائمة الحجر |
| **PLT-03 خارطة الطريق والمقترح** | المعمارية ذات الطبقات الخمس وإضافات v2، نطاق العمل، الافتراضات، المعالم M0–M4 مع نسب دفع قابلة للتعبئة |

### ركيزة الموقع والسلامة (HSE — Part A)


| القسم | الوصف |
|---|---|
| **SEC-01 نظرة عامة** | مؤشر السلامة الكلي (Safety Index)، مؤشرات LTIFR / TRIR، مصفوفة المخاطر 5×5، اتجاه الحوادث، حالة التصاريح، أداء المواقع، الإجراءات العاجلة |
| **SEC-02 الرادار الحي** | أربعة رادارات متحركة باستمرار على Canvas: رادار المخاطر (مسح دائري)، رادار الحساسات (قطبي حي)، رادار مخطط الموقع (حركة العمال والمعدات)، رادار الامتثال ISO 45001 |
| **SEC-03 سجل المخاطر** | سجل كامل مع تسلسل الضوابط الهرمي، المخاطر الكامنة مقابل المتبقية، الإضافة والتعديل والحذف مع الحفظ المحلي |
| **SEC-04 الحوادث** | الحوادث والحوادث الوشيكة، تحليل باريتو للأسباب الجذرية، مسار التحقيق بخمس خطوات، الإجراءات التصحيحية |
| **SEC-05 تصاريح العمل** | لوحة كانبان لتصاريح العمل (أعمال ساخنة، أماكن مغلقة، ارتفاعات، عزل كهربائي…) مع عدّادات انتهاء حية |
| **SEC-06 التفتيش والتدقيق** | جدولة الجولات، نسب الإنجاز، الملاحظات المفتوحة والمغلقة |
| **SEC-07 التدريب والكفاءات** | مصفوفة التدريب (العمال × الدورات)، الشهادات المنتهية والقريبة من الانتهاء |
| **SEC-08 الامتثال ISO 45001** | درجات البنود 4–10، الفجوات، السجل القانوني السعودي (نظام العمل، لائحة السلامة والصحة المهنية، كود البناء السعودي، الدفاع المدني، التأمينات الاجتماعية) |
| **SEC-09 التكاملات** | 16 موصلاً (منصة بلتكس، Biltix DMS، بوابة الحساسات، الكاميرات الذكية، الأجهزة القابلة للارتداء، بوابات الدخول، الأرصاد، GOSI، الموارد البشرية، ERP، Slack، Teams، WhatsApp، البريد، SMS، Webhooks، Google Sheets، Supabase، Power BI) مع مصدر بيانات قابل للتهيئة |
| **SEC-10 التقارير** | تقرير شهري قابل للطباعة/PDF، تصدير CSV/JSON، مشاركة، تقرير صوتي عربي |
| **SEC-11 الإعدادات** | السمة الداكنة/الفاتحة، الأرقام العربية/اللاتينية، ألوان الهوية وشعار الشركة، إدارة البيانات |

### الاتصال بالأنظمة الحقيقية

- **مصدر البيانات**: من قسم التكاملات اختر `JSON API` أو `Google Sheets CSV` أو `Supabase` وأدخل الرابط والمفتاح، ثم «اختبار الاتصال» و«استيراد المخاطر». القالب القياسي للأعمدة قابل للتنزيل من نفس الشاشة.
- **تنبيهات Webhook**: أدخل رابط Webhook (Slack / Teams / n8n / Zapier) ليستقبل التنبيهات الحرجة.
- **الوضع الافتراضي**: محاكاة حية ببيانات توضيحية واقعية تُعاد مزامنة تواريخها تلقائياً مع تاريخ اليوم.

### النشر

المجلد `biltix-hse/` هو جذر النشر (موقع ثابت بالكامل). مشروع Vercel `biltix-risk-ai` مربوط بهذا المستودع مع **Root Directory** = `biltix-hse` بدون أمر بناء؛ الرابط الحي: https://biltix-risk-ai.vercel.app

### المعمارية

راجع `docs/ARCHITECTURE.md` — العقد البرمجي الكامل للوحدات (tokens، مخطط البيانات، واجهات الرسوم والرادارات، محرك البث الحي).
